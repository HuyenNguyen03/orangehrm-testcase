# orangehrm-testcase
Dự án kiểm thử – OrangeHRM (Login Function)
🔥 OrangeHRM Login Testing
📌 Project Overview

Dự án mô phỏng kiểm thử chức năng Đăng nhập (Login) của hệ thống OrangeHRM.
Mục tiêu là xây dựng và thiết kế test case nhằm đảm bảo chất lượng và tính ổn định của chức năng đăng nhập.

🎯 Scope

Chức năng được kiểm thử:

Login với username và password

Validation dữ liệu đầu vào

Điều hướng (navigation)

Session và authentication

Xử lý lỗi và các trường hợp đặc biệt

🧪 Test Coverage

Dự án bao gồm 36 test case, bao phủ các loại kiểm thử:

UI Testing: layout, font, hover, tab navigation

Functional Testing: login flow, redirect, link

Validation Testing: empty input, invalid data, whitespace

Security Testing: SQL Injection, XSS

Performance Testing: spam click, response time

Reliability Testing: mất kết nối mạng

Authentication Testing: session, logout, refresh

🛠️ Test Design

Thiết kế test case với đầy đủ:

Test Steps
